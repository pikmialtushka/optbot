# Ultimate Optimization Bot

## Переменные окружения (Railway)
- `BOT_TOKEN` — токен бота
- `ADMIN_ID` — твой Telegram ID
- `MASTER_KEY` — секретный ключ (придумай сам)
- `SERVER_URL` — URL твоего Railway приложения (после деплоя)

## Деплой
1. Загрузи папку на GitHub
2. Подключи Railway к репозиторию
3. Добавь переменные окружения
4. Deploy!
